"Xanakin's Roleplay Journal for Skyrim" - is a OPEN SOURCE single HTML file that runs entirely in your browser — no internet required after download, no accounts, no servers. It's a personal roleplay companion tool built specifically for Skyrim multiplayer (SkyMP) servers where all interaction is with other players. Everything saves automatically to your browser's local storage.
⚔ Character
Full character sheet with name, race, gender, age, and class
Appearance, backstory, motivations, secrets, and personality fields
Skills, abilities, shouts, and powers
Equipment tracker for weapons, armor, and notable items
Gold / wealth field
World reputation section — your title, standing (Feared, Respected, Infamous etc.), and public perception
Bounty & Wanted status banner that appears at the top of the sheet when active, showing who wants you and why
👥 Players
Track every player character you've met on the server
Store their username, race, class, and usual location
Relationship tag — Ally, Enemy, Neutral, Unknown
RP Status tag — Close Ally, Rival, Romance, Mentor, Debt Owed
Last Seen date
Description, appearance notes, and intel/secrets field
Per-player Encounter Log — a running dated diary of every time you interact with them
Pin any player card to your Notes tab for quick reference
Filter by relationship type, search by name or notes
Freeform tags for custom categorisation
📜 Quests
Log quests with name, status, quest giver, location, and reward
Status types — Active, Rumor/Lead, Completed, Failed
Description and objective field
Progress notes for tracking where you're up to
Filter by status
Freeform tags
🏰 Factions
Track factions and organisations on the server
Standing type — Allied/Member, Neutral, Hostile, Unknown
Visual reputation bar from 0–100 with colour coding (green/amber/red)
Your rank or title within the faction
Description, known members, and notes fields
🗺 Locations
Log discovered places with name, region, and who controls them
Safety rating — Safe, Neutral, Dangerous, Unknown — with colour-coded card borders
Description and notable events that happened there
Filter by safety rating
Freeform tags
📣 Rumors
Record things you've heard in-world with source and notes
Status — Unverified, Confirmed True, Confirmed False
One-click buttons to mark a rumor true, false, or reset it
Filter by status
Visually styled as a corkboard of rumor cards
⚡ Conflicts
Track ongoing feuds, wars, or political situations
Conflict types — Political, Military, Personal Feud, Guild War, Religious, Criminal
Status — Active, Escalating, Simmering, Resolved — colour coded
Parties involved, your involvement, description, and recent developments field
📖 Journal
Per-session journal entries with real date and in-game date
Full long-form entry text
Key events as tags displayed on the entry card
Timeline layout showing entries in chronological order
Freeform tags
✦ Character Arc
A summary field for your character's overall story direction
Milestone tracker — log turning points, revelations, losses, and growth moments
Each milestone has a label, date, and description
Displayed as a visual timeline with ember-glow dots
🖼 Screenshots
Upload local image files directly from your computer (no URL needed)
Drag and drop support
Thumbnail preview before saving
Caption, date, and session link fields
Stored as base64 — fully offline, no external links
📋 Notes
Pinned Notes — pin anything as a quick-reference card, editable anytime
Pre-Session Notes — a freeform scratchpad for goals, follow-ups, and reminders before you log in
Loose Threads — a checklist of unresolved plot hooks and open situations, with tick-to-resolve and delete
👤 Character Profiles
Create unlimited character profiles, each with a name, race, class, and emoji icon
Switch between characters from the dropdown in the top bar — all data loads instantly per character
Every tab's data (quests, players, factions, everything) is stored completely separately per character
Delete any character and their data cleanly
Export any character to a named JSON backup file
Import a previously exported character — restores their data and re-adds them to your profile list
General
Dark and light mode toggle
Auto-saves to browser localStorage on every change
Export any character's full data as a .json file
Import from a backup to restore or transfer data
Works fully offline after the first load (fonts need internet once)
